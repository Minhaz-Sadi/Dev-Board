Question-1: What are the different ways to select an element in the DOM?

We can select elements using getElementById, getElementsByClassName, getElementsByTagName, querySelector, and querySelectorAll.

Question-2: What is the difference between innerHTML, innerText, and textContent ?

innerHTML returns HTML content, innerText gets visible text, and textContent retrieves all text, including hidden elements.

Question-3: What is event delegation in the DOM?

Event delegation is a technique where you add a single event listener to a parent element to handle events for all its current and future child elements, leveraging event bubbling.

Question-4: What is event bubbling in the DOM?

Event bubbling is a mechanism in the DOM where an event triggered on a child element propagates upward through its parent elements in the hierarchy.

Question-5: How do you create, add, and remove elements using JavaScript?

We can create an element using document.createElement(), add it with appendChild() and remove it with removeChild().
